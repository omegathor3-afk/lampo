ECOSYSTEM

Plugins — capability packages.

A plugin declares the capabilities it uses (mouse, keyboard, files, network…), registers tools and skills, and can be enabled or disabled by the owner. Disabled plugins are denied at the permission gate — enforced, not cosmetic.

STRUCTURE READY — REGISTRY FUTURE

Bundled plugins ship with Lampo (computer control, calculator, weather, vision and more). The public plugin registry — with review, permissions display and one-click install — is on the roadmap. Plugin authors can already publish directly into the plugins/ folder.
