Getting started & guides.

Getting started

Install Python 3.11+, install requirements, place a GGUF model in Models/ or point Lampo at Ollama, then run app.py.

Owner Control

Set trust per capability in Settings → Owner control. SAFE allows reads only, CONFIRM asks on every action, FULL_ACCESS runs without asking.

Models & providers

Switch between local GGUF, Ollama and OpenAI-compatible endpoints. Your owner policy and permissions persist across providers.

Tools

Files, terminal, computer control and scheduling — every call is permission-checked before execution.

History

Conversations autosave to SQLite. Search, pin, rename, archive and export as Markdown.

Troubleshooting

Model not responding? Check the server health endpoint. Tool denied? The owner policy decided — review trust levels.
