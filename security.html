SECURITY

The model asks. The policy decides.

Permission enforcement. Every tool call — from the model, a scheduler or a plugin — passes an owner-configured permission gate (SAFE / CONFIRM / FULL_ACCESS per capability) before execution. Denied actions return a structured denial to the model; the pipeline never bypasses the gate, and confirmation fails closed in unattended contexts.

Prompt-injection defense. Tool output and external content are marked as untrusted data, and the owner authority hierarchy is delivered as a system-level instruction on every request. Injection attempts cannot alter trust levels.

Token storage. OAuth tokens are encrypted with Windows DPAPI. No client secrets ship inside the app.
