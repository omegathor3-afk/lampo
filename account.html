ACCOUNT

Lampo Account

Desktop sign-in — LIVE. Sign in with Google inside the app (Account panel). PKCE + DPAPI; no passwords stored.
Cloud database — LIVE. Supabase free tier (Postgres + Row-Level Security). Schema: profiles, devices, conversations, projects, sync metadata.
Desktop cloud sync — LIVE. In-app: Cloud Sync toggle, conversation/project toggles, Sync Now, status, last-synced. Local stays authoritative; sync never touches keys/tokens/files.
Web sign-in — CONFIGURATION REQUIRED. Website login needs a Google Web OAuth client wired into the Supabase Google provider (GCP console → create "Web application" client with this site as origin and the Supabase callback as redirect, then paste into Supabase → Auth → Google). Until then this page is public-only; nothing here is faked.
Account deletion / sign-out-all — FUTURE. Requires the hosted session store (same web client work).

Signed out or signed in, the desktop app works fully offline. The cloud is an optional enhancement — it can never grant or override OwnerPolicy / PermissionGate.
